# OldGuida 关键词翻译、错题停留与品牌更新设计

日期：2026-08-27
状态：已确认，待实施计划

## 背景

OldGuida 是面向中文用户的意大利驾考学习应用。现有题库包含 7193 道意大利语判断题，并已提供中文翻译和中文解析。本次改动在不修改题目与答案的前提下，增加离线驾考词典、题目内关键词查译、错题自动停留，并统一应用名称和图标。

## 目标

- 在现有 `assets/db/quiz.db` 中加入约 500 至 800 个高频意大利驾考单词和固定短语。
- 在首页提供独立的“驾考词典”入口，支持意大利语和中文搜索。
- 在所有显示意大利语题目的页面标出词典关键词，点击后显示中文释义。
- 在设置中允许关闭题目关键词划线和点击查译，首次安装默认开启。
- 增加“错题自动停留”设置，仅在“立刻显示正误”开启时可用。
- 将用户可见的应用名称统一为 `OldGuida`，保留现有应用包标识。
- 使用“方向盘 + 打开的书”作为新应用图标主体，并加入少量意大利三色元素。

## 非目标

- 不接入在线翻译服务。
- 不提供任意单词的机器翻译。
- 不修改现有题目、答案、章节、小节、中文翻译或中文解析。
- 不修改 Android `applicationId`、iOS bundle identifier 或现有发布仓库关系。
- 第一版不加入发音音频、在线词库同步或用户自建词条。

## 已确认的产品决策

- 词典入口只放在首页，不增加底部导航标签。
- 第一版收录高频词汇，而不是覆盖题库中的全部词汇。
- 词条同时支持单词、固定短语和常见词形变化。
- 题目关键词查译覆盖所有出现意大利语题目的页面。
- 点击关键词先显示简短释义，并可进入完整词条。
- 完整词条包含意大利语词条、词性、中文驾考语境释义、常见词形或搭配，以及一条取自题库的中意双语例句。
- 题目关键词翻译默认开启，关闭后独立词典仍可使用。
- 错题自动停留后，答错会一直停留在当前题，直到用户手动点击“下一题”。
- 新图标采用“方向盘 + 打开的书”的方向。

## 数据设计

### 数据库表

词典直接加入现有 `quiz.db`，新增以下表：

```sql
CREATE TABLE keyword_dictionary (
  id INTEGER PRIMARY KEY,
  term TEXT NOT NULL,
  normalized_term TEXT NOT NULL UNIQUE,
  part_of_speech TEXT NOT NULL,
  translation TEXT NOT NULL,
  note TEXT NOT NULL DEFAULT '',
  frequency INTEGER NOT NULL DEFAULT 0,
  sort_order INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE keyword_forms (
  id INTEGER PRIMARY KEY,
  keyword_id INTEGER NOT NULL,
  form TEXT NOT NULL,
  normalized_form TEXT NOT NULL UNIQUE,
  FOREIGN KEY (keyword_id) REFERENCES keyword_dictionary(id)
);

CREATE TABLE keyword_examples (
  id INTEGER PRIMARY KEY,
  keyword_id INTEGER NOT NULL,
  question_id INTEGER NOT NULL,
  rank INTEGER NOT NULL DEFAULT 0,
  UNIQUE(keyword_id, question_id),
  FOREIGN KEY (keyword_id) REFERENCES keyword_dictionary(id)
);

CREATE TABLE dictionary_meta (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
```

`keyword_forms` 同时保存规范词形本身，因此题目匹配只需读取一套匹配数据。一个规范化词形只能对应一个驾考语境词条；遇到语言上的多义词时，将相关驾考含义合并到同一词条，避免点击后出现含义不明的多个结果。

`keyword_examples.question_id` 逻辑关联 `quiz.id`。现有 `quiz.id` 在 7193 道题中非空且唯一，但原表没有主键约束，因此不对该字段添加数据库外键；导入校验负责保证引用有效。

### 索引

- `keyword_dictionary.normalized_term` 唯一索引。
- `keyword_forms.normalized_form` 唯一索引。
- `keyword_forms.keyword_id` 普通索引。
- `keyword_examples.keyword_id, rank` 复合索引。
- `keyword_examples.question_id` 普通索引。

### 规范化规则

- 匹配忽略意大利语大小写。
- 统一直撇号和弯撇号，但保留原文显示。
- 保留重音字母，避免把不同单词错误合并。
- 使用意大利语字母边界判断，不使用只面向 ASCII 的简单 `\b`。
- 固定短语和较长词形优先，已匹配区间不再被短词覆盖。
- 每个词条显式维护允许匹配的词形，不做可能产生误判的自动词干推导。

## 数据库升级与备份

实施前先复制原始 `assets/db/quiz.db` 到带日期的备份文件，并记录原数据库文件校验值。

数据库版本从 3 升到 4，内置数据库的 `PRAGMA user_version` 同步设为 4。

新安装用户直接复制包含完整词典表的内置数据库。已安装用户继续使用原有工作数据库，升级时先创建词典表，再比较 `dictionary_meta` 中的词库版本。只有版本落后时，应用才从新版内置数据库读取并以事务方式更新四张词典表。

同步过程不得替换用户工作数据库，也不得删除或重建 `users`、`favorites`、`wrong_answers`、`quiz_history` 或 `quiz_history_questions`。同步失败时回滚词典事务，题库和用户数据继续可用；界面降级为不显示关键词划线，并记录可诊断错误。

## 词库制作

1. 对 7193 道题的意大利语原文进行词频和短语频率统计。
2. 结合驾考重要性筛选约 500 至 800 个候选词条，不以词频作为唯一标准。
3. 为每个词条整理规范词形、固定搭配、常见变化、词性和中文驾考释义。
4. 为每个词条选择至少一条能清晰体现该含义的现有题目作为例句。
5. 审查中文释义，避免使用脱离驾考语境的泛化翻译。
6. 将词条写入备份后的 `quiz.db`，然后执行完整性检查。

导入脚本应可重复运行，并在相同输入下产生稳定结果。脚本只允许写入四张词典表，不得更新原有题库表。

## 应用结构

### 领域层

- `Keyword`：完整词条模型。
- `KeywordForm`：可匹配词形模型。
- `KeywordMatch`：题目中的起止位置、命中原文和对应词条。
- `KeywordRepository`：封装词典列表、搜索、详情和版本读取。
- `KeywordMatcher`：负责规范化、最长匹配、边界判断和结果缓存。

匹配器首次需要时从 SQLite 加载约 500 至 800 个词条及其词形。匹配结果按稳定的题目 `id` 与词库版本缓存；词库版本变化时清空缓存。

### 统一题目文本组件

新增统一的 `KeywordQuestionText` 组件，接收题目 id、题目文本、原有文本样式和开关状态：

- 开关开启且词库可用时，将命中片段渲染为可点击的青绿色点状下划线。
- 未命中片段完全保留原有样式和换行行为。
- 开关关闭、词库为空或加载失败时，退化为普通文本。
- 点击命中词形后打开释义底部面板，不跳离当前题。

所有显示意大利语题目的页面必须改用该组件，包括练习、模拟考试、题库浏览、收藏、错题复习、历史详情、最终结果以及现有专项题页面。中文翻译和中文解析不做关键词匹配。

## 词典界面

### 首页入口

在首页“通用功能”区域新增“驾考词典”入口，保持现有网格布局和交互方式，不新增底部导航项。

### 词典列表

- 顶部为固定搜索框。
- 支持按意大利语规范词形、常见变化和中文释义搜索。
- 默认按高频程度和人工排序展示。
- 每项显示词条、词性和一行简短中文释义。
- 空结果明确显示“未找到相关词条”。

### 词条详情

- 显示规范词条、词性和完整中文驾考释义。
- 显示常见词形和固定搭配。
- 显示一条题库意大利语例句及其现有中文翻译。
- 例句只读，不在此页面提供答题行为。

### 题目内释义面板

- 首行显示用户实际点击的词形和规范词条。
- 显示词性与简短中文释义。
- 提供“查看完整词条”命令。
- 关闭后保持当前题号、答案状态、滚动位置和计时状态。

## 设置设计

### 题目关键词翻译

- 设置键：`keywordTranslationEnabled`。
- 首次安装默认值：`true`。
- 关闭后不划线、不响应点击；独立词典始终可用。

### 错题自动停留

- 设置键：`stayOnWrongAnswer`。
- 默认值：`false`。
- 仅当 `immediateFeedback` 为 `true` 时显示该选项。
- 关闭“立刻显示正误”后该能力立即失效，但保留用户原选择；再次开启时恢复。

答题逻辑只在同时满足以下条件时停留：

```text
immediateFeedback == true
stayOnWrongAnswer == true
answerIsCorrect == false
```

答错后锁定本题首次答案，防止通过再次点击正确答案覆盖错题结果。正误提示、翻译和解析继续按现有设置显示，计时器继续运行。用户可通过“下一题”或题号导航主动离开；答对仍使用现有延时自动前进逻辑。

## 应用名称与图标

用户可见名称统一为 `OldGuida`，包括首页标题、Android 应用标签、iOS `CFBundleDisplayName` 及其他已支持桌面平台的窗口标题。Dart package 名称和移动端包标识保持不变。

新图标要求：

- 主体为方向盘与打开的书，两者在小尺寸下仍可辨认。
- 使用简洁、扁平、无文字的构图。
- 主色呼应应用现有青绿色，辅以少量意大利红、白、绿。
- 不使用细碎装饰、阴影文字、水印或 Flutter 标志。
- 先生成高清方形母版，再输出 Android 自适应图标所需前景/背景和 iOS 全尺寸图标。
- 检查安全区域，避免圆形、圆角矩形和方形启动器裁切主体。

## 错误处理

- 词典读取失败不阻止题库和答题页面加载。
- 无效词条例句不阻止词条显示，但导入校验必须报告该问题。
- 数据库词典同步使用事务，任何失败均不留下半更新状态。
- 点击关键词时如果词条已失效，关闭加载状态并显示简短错误提示。
- 设置读取失败时使用默认值：关键词翻译开启，错题自动停留关闭。

## 验证方案

### 数据完整性

- 修改前后对 `quiz`、`chapter`、`section` 的行数和内容校验值进行比较。
- 验证 7193 道题的题目、答案、翻译和解析完全未改变。
- 验证词条数量处于 500 至 800 范围内。
- 验证规范词条、匹配词形、中文释义和词性均非空。
- 验证规范化词形唯一，并且所有 `keyword_id` 和 `question_id` 引用有效。

### 自动测试

- 意大利语大小写、标点、直弯撇号和重音字符匹配。
- 固定短语优先、重叠区间处理和部分单词不误匹配。
- 常见词形能回到正确规范词条。
- 意大利语和中文搜索、空结果与词条详情。
- 关键词开关默认值、持久化和关闭后的普通文本降级。
- “立刻显示正误”与“错题自动停留”的可见性和行为组合。
- 答错后不自动前进、不允许覆盖首次答案；手动下一题正常。
- 答对仍按现有逻辑自动前进。
- 数据库从版本 3 升级到版本 4 后用户表数据不变，词典表完整。

### 人工与视觉验证

- 逐类检查所有题目页面中的下划线、点击区域、换行和长文本布局。
- 检查带图片题目中关键词不会与图片、收藏按钮或答案控件重叠。
- 检查词典页面在常见手机宽度下的搜索、列表、详情和空状态。
- 检查设置项条件显示与返回页面后的即时生效。
- 检查 Android 和 iOS 图标在系统桌面、应用列表和启动画面中的清晰度与裁切。

## 验收标准

- 首页可以进入离线驾考词典，并能按中意关键词找到词条。
- 所有题目页面都能按设置正确显示或隐藏可点击关键词。
- 固定短语优先于其内部单词，点击结果符合驾考语境。
- 独立词典不受题目关键词开关影响。
- 错题自动停留只在立刻显示正误开启时可配置，答错后必须手动继续。
- 老用户升级后原有错题、收藏、账号和学习记录保持不变。
- 现有 7193 道题及答案内容不发生变化。
- 应用显示名称为 `OldGuida`，Android 与 iOS 使用新的方向盘加书本图标。
